VITA CMMS نسخه ۱.۰ - راهنمای فارسی

امکانات:
- ثبت کار متنی
- دیکته فارسی با قابلیت SpeechRecognition مرورگر (در مرورگرهای سازگار؛ ممکن است به اینترنت نیاز داشته باشد)
- دسته‌بندی، اولویت، مسئول و موعد
- جستجو و فیلتر
- انجام‌شده/بازگشایی، ویرایش و حذف
- اعلان موعد در زمان اجرای برنامه/فعال بودن صفحه
- خروجی و بازیابی فایل پشتیبان JSON
- PWA و کش آفلاین پس از اولین بارگذاری

نکته مهم:
این نسخه داده‌ها را فقط در حافظه محلی مرورگر همان گوشی نگه می‌دارد. پاک‌کردن داده‌های مرورگر ممکن است اطلاعات را حذف کند؛ مرتب خروجی پشتیبان بگیرید.
اعلان زمان‌بندی‌شده در این نسخه با بررسی دوره‌ای هنگام باز بودن برنامه انجام می‌شود؛ تضمین اعلان در زمان بسته بودن کامل برنامه وجود ندارد. برای اعلان مطمئن در پس‌زمینه به سرویس زمان‌بندی/Push و زیرساخت آنلاین نیاز است.

راه‌اندازی رایگان:
۱) پوشه را در یک مخزن GitHub بارگذاری کنید.
۲) در Settings > Pages گزینه Deploy from a branch را انتخاب و شاخه main و پوشه root را تعیین کنید.
۳) پس از انتشار، نشانی HTTPS سایت را در Chrome اندروید باز کنید.
۴) از منوی Chrome گزینه Add to Home screen یا Install app را انتخاب کنید.
۵) یک‌بار برنامه را باز کنید، اجازه میکروفون و اعلان را در صورت نیاز بدهید.

برای استفاده آفلاین، ابتدا برنامه را با اینترنت باز کنید تا فایل‌ها کش شوند.
برای پشتیبان‌گیری: دکمه «خروجی پشتیبان»؛ برای بازیابی: «بازیابی».

این پروژه نمونه عملیاتی شخصی و محلی است؛ هنوز همگام‌سازی بین دستگاه‌ها، حساب کاربری، گردش‌کار تأیید و اعلان Push سمت سرور ندارد.
